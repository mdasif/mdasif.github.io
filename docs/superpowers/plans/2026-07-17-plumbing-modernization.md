# Blog Plumbing Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modernize the blog's build/deploy pipeline, dependency versions, comments, and contact form without changing the visual theme or layout.

**Architecture:** Move GitHub Pages deploy from the legacy "deploy from branch" builder to a GitHub Actions workflow that runs `npm run build` (LESS/JS compilation, replacing Grunt) then `jekyll build`. Bump Ruby/Jekyll/gems to current versions. Remove the dead Facebook/Disqus comments include and the non-functional PHP contact form, replacing the latter with a static email/social links block.

**Tech Stack:** Jekyll 4.x (Ruby 3.3 via rbenv), GitHub Actions (`actions/deploy-pages`), `less` + `clean-css-cli` + `terser` npm packages replacing Grunt.

## Global Constraints

- Do not change the visual theme, layout, or vendored assets (`bootstrap.css`, `jquery.js`, `bootstrap.js`) — spec non-goal.
- No new comments system is added in this pass — removal only.
- Site continues to deploy to GitHub Pages under `mdasif.github.io` — no hosting migration.
- CSS/JS build output file names/paths stay the same: `css/clean-blog.css`, `css/clean-blog.min.css`, `js/clean-blog.min.js`.

### Task 3: Add GitHub Actions deploy workflow

**Files:**
- Create: `.github/workflows/deploy.yml`

**Interfaces:**
- Consumes: `bundle install` / `bundle exec jekyll build` (Task 1), `npm ci` / `npm run build` (Task 2).
- Produces: automatic build+deploy to GitHub Pages on push to `main`.

- [ ] **Step 1: Create the workflow file**

Create `.github/workflows/deploy.yml`:

```yaml
name: Build and deploy Jekyll site

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Ruby
        uses: ruby/setup-ruby@v1
        with:
          ruby-version: '3.3.6'
          bundler-cache: true

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Install npm dependencies
        run: npm ci

      - name: Build CSS/JS
        run: npm run build

      - name: Setup Pages
        uses: actions/configure-pages@v5

      - name: Build with Jekyll
        run: bundle exec jekyll build --destination _site
        env:
          JEKYLL_ENV: production

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: _site

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: Commit**

```bash

git commit -m "Add GitHub Actions workflow to build and deploy to Pages"
```

- [ ] **Step 3: Push and switch the Pages source setting**

```bash

```

Then in the GitHub repo settings → Pages, change "Build and deployment" → Source to "GitHub Actions" (it currently reads "Deploy from a branch").
